# Visual Anomaly Lab knowledge studio

This curated graph links current capabilities and selected open work to the tracked handbook, roadmap, backlog, ADRs and measurements. The cited documents are authoritative for behavior and measured results. The graph is an index and impact map, not a replacement for those records. Source images, public benchmark payloads and runtime data remain outside this directory.

Open this Git checkout in [Knowledge Studio](https://github.com/VitalyVorobyev/knowledge-studio). Run the pinned validator from CI when model files change. Unknown owners, effort ranges and dates remain unknown. The backlog retains its S/M/L sizing in each relevant work package's `details.backlog_size`. Review graph changes in the same PR as documentation and code changes.
